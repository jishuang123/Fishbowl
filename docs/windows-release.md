# Fishbowl Windows 使用说明

## 首次启动

1. 在 Windows x64 上把整个压缩包解压到普通文件夹，双击 `Fishbowl.exe`。保留同目录的 `_internal`，无需安装 Python 或 Node.js。当前包未签名，仅供本机使用；如果 Windows 提示来源不明，先核对压缩包来源。
2. 等大肥鱼出现后，按住角色拖动，或点击头部和身体试试互动。桌宠显示、互动和角色导入无需 API Key。
3. 右键桌宠或任务栏通知区的鱼形图标，可打开聊天、切换角色、配置互动、静音或退出。找不到图标时查看通知区的隐藏图标；双击鱼形图标可重新显示桌宠。

## 配置 DeepSeek 聊天

1. 从 [DeepSeek 开放平台](https://platform.deepseek.com/) 获取自己的 API Key。
2. 在桌宠或托盘右键菜单打开当前角色的聊天，点击「API 设置」。粘贴 Key，保留默认模型或从下拉框选择，点击「保存」。
3. 输入消息，按 Enter 发送、Shift+Enter 换行。回复会逐段显示；问「现在几点？」可试用本机时间工具，查询结果会显示在聊天卡片中。完整回复才朗读。

Key 保存在本机用户目录的 `deepseek.json`，应用直接向 DeepSeek 发送聊天请求。不要分享该文件、把 Key 放进角色配置或提交到 Git。如果设置过 `DEEPSEEK_API_KEY` 环境变量，它优先于界面保存的 Key；修改环境变量后重启。界面清空 Key 并保存只会清除本地文件中的 Key。

## 导入角色和设置互动

1. 准备有权使用的完整 Cubism 模型，先解压，保留入口、贴图和动作等资源的相对位置。
2. 右键 →「切换角色」→「导入 Live2D 模型…」，选择目录内的 `.model3.json`。程序会复制所需资源并自动切换；在同一菜单可以切回大肥鱼。每个角色各自保存最近 10 轮完整对话，「清空记忆」只影响当前角色；静音和 API Key 全局共享。
3. 切换到要配置的角色，右键 →「角色互动设置…」。分别在「点击头部」「点击身体」「随机待机」选保留默认、自定义或关闭。自定义时可组合动作、表情和语音，不需要的项选「无」；可用「导入音频…」选择 WAV、MP3 或 OGG。
4. 点击「保存」立即应用。随机待机约每 45–100 秒尝试一次，点击和拖动优先。聊天生成或朗读时会跳过互动语音；开启全局静音后立即停止声音和口型，取消静音不会补播。

## 常见问题

| 现象 | 怎么处理 |
| --- | --- |
| 双击无反应，或提示缺少组件 | 确认完整解压且 `_internal` 与 EXE 同目录，检查下方的启动日志。 |
| 窗口有背景但没有角色，或加载失败 | 确认模型资源完整、显卡驱动支持 WebGL2。首次运行可能较慢；如果持续失败，查看运行日志。 |
| 401、402、429 或网络失败 | 401 检查 Key 和环境变量优先级；402 检查 DeepSeek 余额；429 稍后重试；网络失败检查到 DeepSeek 的连接。 |
| 找不到可导入的模型 | 选完整目录中的 `.model3.json`，不是 ZIP、PSD、`.moc3` 或旧版 `.model.json`。缺失引用文件、资源过大或模型不兼容会导致导入或显示失败。 |
| 点击没有自定义动作或语音 | 检查当前角色、触发页是否为「自定义」、是否已保存；模型没有注册的动作或表情不会出现在列表里。拖动不会触发点击。 |
| 有文字但没声音，或有声音但嘴不动 | 先检查全局静音、Windows 输出设备与已安装的系统语音。导入模型缺少对应嘴部参数时仍可播放，但不会联动嘴部。 |

在资源管理器地址栏输入 `%LOCALAPPDATA%\Fishbowl\Fishbowl\` 可找到运行日志 `fishbowl.log` 与启动故障日志 `startup-error.log`（出现启动异常时生成）。同一目录保存 Key、记忆、导入角色、互动映射和静音选择；源码运行版和 EXE 共用它，更新程序无需搬运或覆盖这些文件。对外求助时只提供脱敏错误摘要，不要上传整个目录。

## 素材与分发

本机包内置大肥鱼，原画及拆分：神宫凉子；Live2D 建模：霓虹猫_NeonNeko。原模型须知限制完整模型再分发，半尺寸贴图也属于该模型资源。不要公开上传此 EXE 文件夹或其 ZIP。SDK 与模型的许可相互独立，随包的许可文本见 `_internal/licenses/`；公开分发程序前另行核对 [Live2D 发布许可](https://www.live2d.com/en/sdk/license/) 与各依赖条款。
