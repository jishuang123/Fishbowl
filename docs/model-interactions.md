# 大肥鱼动作筛选与 V0.2 交互

检查对象为原始 `DeepSeek免费公皮.zip` 中的动画、表情、cdi3 参数说明、physics3 物理映射和 vtube 配置，并对本轮启用的内容完成实际渲染检查。原 ZIP 及其中的文件保持不变，适配文件由 `tools/prepare_web.py` 生成在本机资源目录。

## 动作选择

8 个动作的原始 Meta.Loop 全部为 true。切换动作直接循环会反复切换姿势，故本轮只对选中的一对动作生成单次播放副本，并设置淡入/淡出。

| 原始动作 | 时长（秒） | 参数与用途 | 本轮决定 |
| --- | --- | --- | --- |
| IDLE | 5.983 | 泪水、汗滴、装饰等效果参数；不直接驱动眨眼或呼吸 | 不用于点击，也不作为自动待机动作 |
| 默认手切举手 | 1.133 | Movement2 从 0 到 1；cdi3 命名为“抚胸” | 启用：点身体抬手至胸前 |
| 举手切默认手 | 1.017 | Movement2 从 1 回到 0 | 启用：短暂停留后自动回位 |
| 狗尾草切换出来 | 1.233 | Movement1 从 0 到 1，同时关闭 Movement3；涉及道具和手指细节 | 可作为后续道具互动候选，本轮仅静态检查 |
| 狗尾草切回默认手 | 1.133 | Movement1 从 1 到 0，复位对应细节 | 与上条配对；本轮未实播 |

| 脱捕 | 13.150 | 同时控制头部、眼睑、嘴、位置和效果；vtube 配置将其用于追踪丢失 | 不适合本轮短点击反馈，未接入 |

抚胸动作已实际播放并查看停留阶段截图。文件名“举手”不是挥手循环。抚胸过程中继续点击身体会被忽略，不排队、不叠加。返回后恢复该动作拥有的参数；不会把当前的视线、呼吸或表情保存成新的基础姿态。

## 表情选择

从包内 23 个表情中选用 3 个短暂反馈：脸红、爱心眼、`＞＜` 开心眼。点角色头部依次切换，每次约 2.5 秒后恢复默认。生成的副本完整写入这三类效果所涉及的 key3/key4/key5/key6/key7，使用 Overwrite 混合，并提供 Neutral 表情，避免上一种眼型或脸红残留。原始表情文件不改动。

服装、体型、尾巴开关属于持续外观设置，暂不作为普通点击反馈。哭泣、黑脸等其他情绪留待后续明确映射，本轮没有逐项实播。

## 鼠标跟随

原模型 physics3 将 AngleX/AngleY 输入转换为 ParamAngleX/ParamAngleY 输出，vtube 配置也以 AngleX/AngleY/AngleZ 作为头部输入。故将官方示例的头部输入调整至 AngleX/Y/Z，保持模型自带物理系统；眼球使用 ParamEyeBallX/Y。沿用官方 CubismLook 和目标点平滑，限制跟随幅度。

桌面端每约 33 毫秒读取一次系统鼠标坐标，换算到桌宠窗口的逻辑坐标，再通过 QWebChannel 发送方向。鼠标位于窗口外仍然跟随；不记录轨迹。浏览器独立预览使用窗口内指针事件，离开页面则回到中心。拖动角色期间暂时回正，释放后继续跟随。

## 点击、拖动与渲染

- 左键移动达到 6 个屏幕逻辑像素后才开始拖动。短点击和拖动互斥；失焦、取消捕获、右键菜单会取消拖动状态。
- 点击后在渲染完成的帧中读取该像素 alpha；透明背景不触发反应。读取只发生在点击时。
- 角色画布上部 35% 的可见像素触发表情，其余可见区域触发抚胸。当前是按画布高度分区，并非模型骨骼级头部命中。
- 只登记不含眼睑曲线的抚胸动作，故这两段动作播放时仍允许官方自动眨眼；准备脚本会拒绝将含眼睑曲线的动作加入这份配置。
- 所有 SDK 参数更新继续走官方模型和渲染流程；未引入第二套 Live2D 引擎。

## 验证与证据

`tools/verify_interactions.py` 使用本机 Chrome，验证四方向眼睛/头部跟随、透明背景点击忽略、三种表情显示与恢复、手势单次播放及回位、忙碌时忽略重复点击、动作结束后眼球可重新回正、拖动不触发反应；每个阶段均保存截图。

本地证据目录：`.local/evidence/interactions/`。`result.json` 记录 7 组场景通过、网页及 SDK 错误为 0。主要截图包括 look-left/right/up/down、expression-Blush/Hearts/Happy、hand-to-chest、gesture-reset 和 gaze-reset-after-gesture。

`tools/verify_desktop.py` 另外检查真实 Qt WebEngine、窗口外全局鼠标跟随、桌面点击反馈、拖动、透明合成及右键退出；托盘退出使用 `--exit-via tray`。最终结果保存在 `.local/evidence/desktop-menu.json` 与 `desktop-tray.json`。

尚未验证其他显卡、混合缩放多屏和长期运行。狗尾草、竖食指、脱捕及其他 20 个原始表情不在本轮动态验收范围。
