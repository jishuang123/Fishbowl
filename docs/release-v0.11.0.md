# Fishbowl v0.11.0 · 首次源码发布

Fishbowl 是一个 Windows Live2D 桌宠项目。桌宠支持鼠标跟随、拖动、点击互动和低频待机动作，也可以导入角色，为各角色设置动作、表情和语音。

- DeepSeek 聊天支持流式回复、时间查询工具和角色独立的本机会话记忆。
- Windows 本机语音可朗读完整回复并联动口型，播放遵守全局静音。
- 渲染默认约 30 帧，窗口隐藏时暂停绘制。

## 如何运行

按仓库 README 的「从源码准备」操作。需要 Windows x64、Python 3.11、Node.js，以及自行取得的官方 Cubism SDK for Web 5 R5 ZIP 和作者配布的大肥鱼模型 ZIP。完成资源准备和前端构建后可运行桌宠。API Key 仅在使用聊天时配置。

## 下载范围与许可

本次发布范围是 Git 标签中的源码和文档。源码归档包含 MIT 许可文本。模型素材、SDK、构建产物和本机用户数据均不在归档中。

大肥鱼原画及拆分为神宫凉子，Live2D 建模为霓虹猫_NeonNeko。模型及其适配资源遵守作者的配布须知，Live2D SDK 及相关组件适用各自的许可。含大肥鱼模型的本机 Windows 包不作为 GitHub 发布附件。
