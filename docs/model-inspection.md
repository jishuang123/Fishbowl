# Fishbowl V0.1：大肥鱼模型初检

检查日期：2026-11-02。对象：工作区中的 `DeepSeek免费公皮.zip`。

后续进展：现已完成官方示例及 PySide6 桌面验证，见 [V0.1 验证记录](validation-v0.1.md)。下文保留首次静态检查时的结论与边界。

结论：模型主要资源齐全，可以进入官方 Web 示例的加载验证。此次仅做静态检查，尚未证明 Cubism Core 能成功解码模型，也未验证 Windows 透明渲染、动画观感和鼠标交互。

## 检查证据

- ZIP CRC 全量检查通过；共 47 个文件，36 个 JSON 文件全部解析成功。
- 压缩包 SHA-256：`3a786f7d75a93295e821ca7dba3fa53143b00dcfa2afac8bc060992dabe9328f`。
- ZIP 内中文名称按 GBK 恢复后，可与模型入口的 Unicode 路径匹配；后续解压需避免文件名乱码。
- 模型入口：`DeepSeek免费公皮/DeepSeek/大肥鱼.model3.json`。
- 入口引用的 moc3、5 张贴图、physics3、cdi3 文件全部存在。
- moc3 文件头为 `MOC3`，其后版本字节为 `05`；SDK 兼容性留待实际加载验证。
- cdi3 列出 509 个参数条目；这不是对 moc3 内部参数的运行时枚举。

## 动作与表情

包内有 8 个 motion3 文件、23 个 exp3 文件，但入口的 FileReferences 没有 Motions 和 Expressions。接入时需要在本地生成适配入口或显式加载，不能假定加载模型入口便会自动播放这些文件。

动作包括 IDLE、举手切默认手、狗尾草切回默认手、狗尾草切换出来、竖手指切出来动画、竖手指切回默认、脱捕、默认手切举手。文件名“脱捕”按原包记录，实际含义待播放确认。

8 个动作的 Meta.Loop 全部为 true；切换类动作是否需要单次播放，应在实际验证后由控制层决定。

IDLE 时长 5.983 秒，曲线没有直接驱动 ParamEyeLOpen、ParamEyeROpen 或 ParamBreath，因此不能凭 IDLE 文件认定自然眨眼和呼吸已经实现。

入口已定义 EyeBlink 组，包含 ParamEyeROpen 和 ParamEyeLOpen；cdi3 中也有 ParamBreath。可以据此进行眨眼、呼吸驱动验证，但仍需确认实际效果。LipSync 组为空，后续语音阶段需要单独映射。

表情涵盖脸红、流泪、爱心眼、圈圈眼、眼镜、体型、服装、尾巴和手势等；表情效果尚未实测。
